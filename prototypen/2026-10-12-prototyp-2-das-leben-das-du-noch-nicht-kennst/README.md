# Prototyp 2 · Das Leben, das du noch nicht kennst

**Stand:** 12.10.2026 · **Status:** DRAFT, spielbereit, intern getestet · **keine Produktfreigabe** (FACH-LAB-VORSCHLAG / PETRA REVIEW)
**Auftrag:** Petras Wahl von Variante 2 nach Prototyp 1 (`co-work-briefs/2026-10-12-prototyp-2-realistisches-moegliches-leben.md`)

Ein 15-Minuten-Erlebnis in jeder normalen KI: Der Mensch erlebt eine realistische, überraschende Version **seines eigenen Lebens**, die an einer Stelle abgebogen ist. Danach entsteht freiwillig eine Verbindung zum echten Leben und, wenn er mag, ein winziger Alltagsversuch. Keine App, keine Kosten, kein Betrieb.

**Dramaturgie:** Schwelle (Vorstellung wie im Zug) → A: mitten in einer Szene, die Abzweigung ist sichtbar → B: Eintauchen, die Figuren fragen und sie füllt die Lücken selbst → C: ungeahnte Wendung ohne Katastrophe und ohne glatten Erfolg → Strich, „keine Vorhersage" → D: „Gab es einen Moment, der dich überrascht oder gereizt hat?" → E: freiwilliger Funke (höchstens 15 Minuten, Wenn-dann, in ihren Worten).

**Unterschied zu Prototyp 1** (`prototypen/2026-10-12-ein-leben-das-du-noch-nicht-kennst/`): keine Fantasie, sondern das eigene Leben; eine Brücke zur Wirklichkeit; die Lücken füllt der Mensch selbst statt der KI.
