# Ein Leben, das du noch nicht kennst · Prototyp A

**Stand:** 12.10.2026 · **Status:** DRAFT, spielbereit, intern getestet · **keine Produktfreigabe** (FACH-LAB-VORSCHLAG / PETRA REVIEW)
**Auftrag:** `co-work-briefs/2026-10-12-interaktives-ki-erlebnis-moegliche-leben-prototyp.md`

Ein 10-Minuten-Erzählspiel in jeder normalen KI (ChatGPT, Claude). Ein Mensch nennt einen Gegenstand in seiner Nähe und landet mitten in einem anderen möglichen Leben. Keine App, keine Datenbank, keine Kosten, kein Betrieb.

| Datei | Inhalt |
|---|---|
| `STARTPROMPT.md` | Der ganze Prompt zum Kopieren (Fassung 0.2) |
| `ANLEITUNG-PETRA.md` | So spielt man es in 2 Minuten |
| `TESTVERLAEUFE.md` | 3 Blindtests (Sonnet, Haiku, Opus), Stärken, Schwächen, Änderungen 0.1 → 0.2, Gegenprobe, Grenzen, vollständige Verläufe |

**Dramaturgie:** Schwelle (Gegenstand + freiwilliger Vorname) → mitten hinein mit kleinem Rätsel → die Welt atmet (eigene Regel, eigene Worte kommen zurück) → Wendung → Andenken → zurück (klar als Fiktion, keine Deutung).

**Weiterentwicklung:** Version B (Brücke ins echte Leben) liegt als ungetesteter Entwurf in `prototypen/2026-10-12-version-b-ein-leben-zum-ausprobieren-ENTWURF.md`. Version A wird dadurch nicht verändert.
