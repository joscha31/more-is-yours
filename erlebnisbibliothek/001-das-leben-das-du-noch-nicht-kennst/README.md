# Erlebnis 001 · Das Leben, das du noch nicht kennst

**Fassung:** 1.1 · **Stand:** 13.10.2026 · **Status:** DRAFT, intern getestet (5 Blindtests + 2 Gegenproben), bereit für erste Testpersonen · FACH-LAB-VORSCHLAG / PETRA REVIEW, **keine Produktfreigabe, nichts veröffentlicht**

**In einem Satz:** Du erlebst eine realistische, überraschende Version deines eigenen Lebens, an einer von 12 möglichen Stellen abgebogen, bekommst eine Postkarte aus diesem Leben und darfst, wenn du magst, einen winzigen Versuch mit in deinen Alltag nehmen. Mit einer neuen Zahl erlebst du ein ganz anderes Leben.

**Dauer:** etwa 15 Minuten je Leben · **Läuft in:** ChatGPT, Claude (beste verfügbare Modelle) · **Kosten:** keine zusätzlichen

**Dramaturgie:** Schwelle (Vorstellung wie im Zug + früher gern gemacht + Zahl 1 bis 12) → mitten hinein, die Abzweigung ist sichtbar → Eintauchen, die Figuren fragen und der Mensch füllt die Lücken selbst → ungeahnte Wendung → Postkarte aus diesem Leben → Strich, „keine Vorhersage" → eine einzige Frage → freiwilliger Funke → Ausgang mit dem Angebot einer neuen Zahl.

Antwort.
