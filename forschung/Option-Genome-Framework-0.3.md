**Geltungsbereich:** fachliche Content-Library

## Worum es geht

Das Option Genome beschreibt die reale wirtschaftliche Außenwelt.

Es soll einer Frau verständlich zeigen:

- Wie funktioniert dieser Weg?
- Wer zahlt?
- Wofür wird gezahlt?
- Wie kommt sie an Arbeit, Aufträge oder Käufer?
- Wie sieht ein normaler Arbeitstag aus?
- Wie planbar ist das Einkommen?
- Was kostet der Einstieg?
- Was passiert, wenn es gut läuft?
- Was wird oft schöner dargestellt, als es ist?
- Was muss sie vorher in der Realität prüfen?

Das Option Genome sagt nicht: „Dieser Weg ist gut“ oder „dieser Weg ist schlecht“.

---

# 1. Grundregeln

1. Neutral beschreiben, nicht loben und nicht abwerten.
2. Keine erfundenen Zahlen.
3. Zahlen brauchen Quelle, Datum und Region.
4. Wenn etwas nicht sicher bekannt ist, steht dort ehrlich `unbekannt` oder `stark abhängig vom Einzelfall`.
5. Verschiedene Unterformen werden nicht künstlich gleichgemacht.
6. Der normale Dienstag entsteht nur aus belegten Daten.
7. Wachstum wird extra betrachtet.
8. Fehlendes Wissen über die Option wird recherchiert. Die Frau wird nicht getestet, nur weil uns Daten fehlen.
9. `nicht anwendbar` ist ein erlaubter Wert.

---

# 2. Drei Ebenen einer Option

## Optionsfamilie
Die grobe wirtschaftliche Form.

Beispiele:
- Anstellung
- selbstständige Dienstleistung
- digitales Produkt

## Optionsvariante
Eine wichtige Unterform.

Beispiele:
- Minijob
- reguläre Teilzeit
- Projekt-Freelancing
- Retainer
- statischer Download
- Template

## Rolle / konkrete Tätigkeit
Die tatsächliche Arbeit.

Beispiele:
- Buchhaltung
- Verkauf
- Copywriting
- Webdesign

Warum diese drei Ebenen?

Weil zum Beispiel „Teilzeit“ allein noch nicht sagt, wie der Alltag wirklich aussieht.

# 3. Grunddaten jeder Option

Jede Option bekommt:

- Name
- Optionsfamilie
- Optionsvariante
- ggf. Rolle / konkrete Tätigkeit
- Region
- Prüfdatum
- Version
- Status
- Quellen
- Vertrauensgrad
- offene Fragen
- Dinge, die nicht verallgemeinert werden dürfen

Vertrauensgrad:
- hoch
- mittel
- niedrig
- offen

---

# 4. Die vier Grundfragen

Jede Option muss einfach beantworten:

1. **Wer zahlt?**
2. **Wofür wird gezahlt?**
3. **Wie wird die Leistung oder das Produkt geliefert?**
4. **Wie kommt die Frau überhaupt an den Arbeitgeber, Auftraggeber oder Käufer?**

Diese vier Fragen bilden die wirtschaftliche Grundmechanik.

---

# 6. Regeln für Zahlen

Eine Zahl wird nur eingetragen, wenn sie sinnvoll belegt werden kann.

Mögliche Kennzeichnung:

- belegt
- belegte Spanne
- Schätzung
- stark abhängig vom Einzelfall
- unbekannt

Bei Einkommen gilt besonders:

Keine allgemeine Euro-Zahl für eine ganze Optionsfamilie, wenn die Unterschiede zwischen Tätigkeit, Markt, Region und Erfahrung zu groß sind.

---

# 7. Einkommensentwicklung und Skalierbarkeit sind nicht dasselbe

Wir fragen getrennt:

> **Wie kann das Einkommen wachsen?**

und

> **Wie weit kann das Einkommen wachsen, ohne dass die persönliche Arbeitszeit im gleichen Maß mitwächst?**

Beispiel:
Eine Angestellte kann durch mehr Stunden oder höheren Lohn mehr verdienen. Das ist Einkommensentwicklung, aber nicht automatisch Skalierung.

---

# 8. Kosten und Marge sind nicht dasselbe

## Kostenstruktur
Wird bei jeder Option betrachtet, wenn relevant.

## Marge / Überschuss
Nur dort, wo es fachlich Sinn ergibt.

Bei Anstellung kann stehen:

> nicht anwendbar

Dort können stattdessen Fahrtkosten, Betreuungskosten oder andere persönliche Kosten wichtig sein.

---

# 9. Absicherung

Jede Option soll zeigen:

- Welche Absicherung ist im Modell bereits eingebaut?
- Was muss die Frau selbst organisieren?
- Welche Themen sind wichtig, z. B. Krankheit, Urlaub, Altersvorsorge oder Einkommensausfall?

Keine individuelle Versicherungsberatung.

---

# 10. Rechtliche Besonderheiten

Jede Option soll zeigen, welche rechtlichen Themen typischerweise wichtig sind.

Beispiele:
- Arbeitsrecht
- Minijob-Regeln
- Gewerbe / Freiberuflichkeit
- Sozialversicherung
- Verbraucherrecht
- Widerruf
- Umsatzsteuer
- Urheber- und Lizenzrechte

Keine individuelle Rechtsberatung.

---

# 11. Der normale Dienstag

Kernfrage:

> **Willst du den Alltag, der dieses Einkommen produziert?**

Der Dienstag zeigt nur Dinge, die wir aus der Option wirklich wissen.

Mögliche Bausteine:
- Kundenkontakt
- Akquise
- Verkauf
- Sichtbarkeit
- Content
- Administration
- Termine
- Team
- Lieferung
- Vorbereitung
- Leerlauf
- Ortsbindung

Keine erfundenen Uhrzeiten und keine erfundenen Kundenszenen.

---

# 12. Was passiert, wenn es funktioniert?

Wir betrachten vier Stufen:

1. Start
2. stabil
3. Wachstum
4. größer / neue Rolle

Dabei prüfen wir zum Beispiel:

- Wird der Kalender voll?
- Muss spezialisiert werden?
- Müssen Preise steigen?
- Braucht es ein Team?
- Entsteht Führungsverantwortung?
- Wird mehr Kapital nötig?
- Entsteht eine neue Abhängigkeit von Plattformen?
- Verändert sich die persönliche Zeitbindung?
- Verändert sich die Rolle der Frau?

---

# 13. Realität statt Romantik

Zu jeder Option gehören außerdem:

- Was wird romantisiert?
- Was unterschätzen Einsteigerinnen?
- Welche typischen Engpässe gibt es?
- Welche kleinen Realitätschecks sind sinnvoll?
- Welche Annahme soll jeder Test klären?
- Was wissen wir noch nicht?

---

# 14. Wann ist eine Goldstandard-Option gut genug?

Für den ersten Pilot reicht eine Option, wenn:

- die wichtigen Felder befüllt sind,
- offene Punkte klar markiert sind,
- Zahlen belegt sind,
- Varianten sichtbar sind,
- der normale Dienstag ohne Fantasie beschrieben werden kann,
- Wachstum beschrieben ist,
- Romantisierungen und Anfängerfallen sichtbar sind,
- kleine Realitätschecks möglich sind.

---

# 15. Erste Goldstandard-Optionen

1. Teilzeit / Nebenjob
2. Freelancing / Done-for-you
3. Digitales Produkt

Diese drei dienen als Belastungstest für das Grundgerüst.

Danach werden die weiteren Startoptionen entwickelt.

# 16. Technische Regel

Claude Code setzt die freigegebene Fachlogik um.

Claude Code darf nicht:

- wirtschaftliche Inhalte erfinden,
- Zahlen schätzen,
- neue Felder mit eigener Bedeutung ergänzen,
- Fachregeln verändern.
