# MORE IS YOURS – OPTION GENOME STRUKTUR

**Stand:** 15.09.2026  
**Status:** PETRA APPROVED  
**Zuständig fachlich:** Option Genome Lab

## Zweck

Diese Datei hält die von Petra freigegebenen Grundregeln für das Option Genome fest.

Das Option Genome beschreibt die reale wirtschaftliche Außenwelt: Wie entsteht Geld, wie sieht die Arbeit wirklich aus, wo liegen Risiken und was verändert sich, wenn ein Weg funktioniert?

## 1. Drei Ebenen statt zu grober Optionen

Eine Option wird künftig in drei Ebenen gedacht:

1. **Optionsfamilie** – die grobe wirtschaftliche Form, z. B. Anstellung oder selbstständige Dienstleistung.
2. **Optionsvariante** – eine wichtige Unterform, z. B. Minijob oder reguläre Teilzeit.
3. **Rolle / konkrete Tätigkeit** – z. B. Buchhaltung, Verkauf, Copywriting oder Webdesign.

Warum: Die gleiche Geldform kann einen völlig anderen Arbeitsalltag haben.

## 2. Neues Grundfeld: Wer zahlt – und wofür?

Statt nur zu fragen:

> Wofür zahlt der Kunde?

wird fachlich allgemeiner gefragt:

> **Wer zahlt – und wofür?**

Das funktioniert für Arbeitgeber, Auftraggeber, Käufer, Plattformen und andere Zahler.

## 3. Neues Grundfeld: Wie entsteht Zugang zum Einkommen?

Statt nur „Kundengewinnung“ wird allgemeiner gefragt:

> **Wie entsteht Zugang zum Einkommen?**

Beispiele:
- Bewerbung / Stellenmarkt
- Akquise
- Empfehlungen
- Plattformen
- Content
- SEO
- Werbung
- Partnerschaften

`Akquiseanteil` darf zusätzlich als Arbeitsrealität bestehen bleiben.

## 4. Einkommensentwicklung und Skalierbarkeit bleiben getrennt

Zwei verschiedene Fragen:

> **Wie kann das Einkommen wachsen?**

und

> **Wie weit kann das Einkommen wachsen, ohne dass die persönliche Arbeitszeit im gleichen Maß mitwächst?**

Mehr verdienen ist nicht automatisch Skalierung.

## 5. Keine erzwungenen Einkommenszahlen

Eine Zahl wird nur eingetragen, wenn sie für eine konkrete Variante, Rolle, Region und Entwicklungsstufe ausreichend belastbar ist.

Wenn nicht, wird ausdrücklich festgehalten:
- stark abhängig vom Einzelfall
- unbekannt
- nicht sinnvoll als allgemeine Zahl anzugeben

Keine Zahl wird erfunden, nur damit das Matching eine Zahl hat.

## 6. Kosten und Marge werden getrennt

### Kostenstruktur
Kann grundsätzlich bei jeder Option betrachtet werden.

### Marge / Überschuss
Wird nur dort beschrieben, wo das fachlich sinnvoll ist.

Bei Anstellung kann `nicht anwendbar` stehen. Dort sind eher Dinge wie Fahrtkosten, Betreuungskosten und Nettoeffekt wichtig.

## 7. Neues Feld: Absicherung / soziale Absicherung

Jede Option soll zeigen, wie die Absicherung grundsätzlich funktioniert.

Zum Beispiel:
- was ist im Modell bereits eingebaut?
- was muss die Frau selbst organisieren?
- welche Themen sind besonders wichtig, z. B. Krankheit, Urlaub, Altersvorsorge oder Einkommensausfall?

Das ist keine individuelle Rechts- oder Versicherungsberatung. Es beschreibt die Struktur des Weges.

## 8. Neues Feld: rechtliche / regulatorische Besonderheiten

Jede Option soll sichtbar machen, welche rechtlichen Bereiche typischerweise wichtig sind.

Beispiele:
- Arbeitsrecht
- Minijob-Regeln
- Gewerbe oder Freiberuflichkeit
- Sozialversicherung
- Verbraucherrecht
- Widerruf
- Umsatzsteuer
- Urheber- und Lizenzrechte

Auch hier gilt: keine individuelle Rechtsberatung. Das Feld zeigt, was geprüft werden muss.

## 9. Vier einfache Grundfragen für jede wirtschaftliche Option

Jede Option muss verständlich beantworten:

1. **Wer zahlt?**
2. **Wofür wird gezahlt?**
3. **Wie wird die Leistung oder das Produkt geliefert?**
4. **Wie kommt die Frau überhaupt an den Arbeitgeber, Auftraggeber oder Käufer?**

Diese vier Fragen bilden zusammen die wirtschaftliche Grundmechanik.

## Weiterhin gültig

Zusätzlich bleiben die bereits freigegebenen drei Dienstag-Felder verbindlich:

- Leistungserbringung / Lieferung
- Recherche / Vorbereitung
- Leerlauf / Warten

Der normale Dienstag darf nur aus belegten Daten entstehen. Keine erfundenen Tagesgeschichten.

## Technische Folge

Claude Code darf diese Regeln technisch abbilden, aber keine neue Fachlogik ergänzen.

Wenn eine technische Entscheidung neue fachliche Bedeutung erzeugen würde, kommt sie als CONTENT GAP zurück ins Option Genome Lab.
